# Partners Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the hardcoded, untranslated Partners marquee into an admin-editable, 3-language (uz/ru/en) list of partner names with optional website links.

**Architecture:** New `Partner` model in `apps/pages` following the existing `WhyUsItem`/`StatItem` pattern exactly (`OrderedActiveModel` + `modeltranslation` + a standalone admin list). `LandingView` passes the active, ordered queryset into the template context; `_partners.html` renders it in place of the hardcoded `<span>` list, preserving the existing marquee CSS animation (which requires the item list to be duplicated back-to-back — see Task 4).

**Tech Stack:** Django 5.2, django-modeltranslation, django-unfold admin, existing `AutoTranslateAdminMixin`. No new dependencies.

## Global Constraints

- No logos/images — text-only, matching the current visual look (per spec decision).
- `name` is per-language translatable (uz/ru/en) via `modeltranslation`, matching every other admin content model in this codebase.
- `website_url` is optional (`blank=True`); template links the name only when set.
- Model must subclass `apps.common.models.OrderedActiveModel` (gives `order` + `is_active` for free).
- Admin class must use the established stack: `AutoTranslateAdminMixin, ModelAdmin, TabbedTranslationAdmin` (see `apps/pages/admin.py::WhyUsItemAdmin` for the exact reference shape).
- Seed the current 7 names (Cambridge, IELTS, Pearson, Khan Academy, Coursera, Oxford, British Council) via a data migration with empty `website_url`, so the site never goes blank on deploy.
- Full spec: `docs/superpowers/specs/2026-07-10-partners-section-design.md`.

"""Seed the 7 partner names that were previously hardcoded in
templates/sections/_partners.html, so the marquee isn't empty on first deploy.
website_url is left blank — an admin can fill it in later per partner.
"""
from django.db import migrations

PARTNERS = [
    "Cambridge", "IELTS", "Pearson", "Khan Academy", "Coursera", "Oxford",
    "British Council",
]


def seed_partners(apps, schema_editor):
    Partner = apps.get_model("pages", "Partner")
    if Partner.objects.exists():
        return
    for i, name in enumerate(PARTNERS):
        Partner.objects.create(
            order=i, is_active=True,
            name=name, name_uz=name, name_ru=name, name_en=name,
            website_url="",
        )


def noop(apps, schema_editor):
    # Data-only seed; nothing to undo (leaving the rows is harmless).
    pass


class Migration(migrations.Migration):
    dependencies = [
        ("pages", "0007_partner"),  # confirm this matches Task 1's generated filename
    ]

    operations = [
        migrations.RunPython(seed_partners, noop),
    ]
```

class PartnersSectionTests(TestCase):
    """LandingView passes partners to the template; _partners.html renders them."""

    def test_partner_name_renders_on_landing_page(self):
        body = self.client.get("/uz/", follow=True).content.decode("utf-8", "replace")
        self.assertIn("Cambridge", body)

    def test_link_wraps_name_when_website_url_set(self):
        Partner.objects.filter(name="IELTS").update(website_url="https://www.ielts.org")
        body = self.client.get("/uz/", follow=True).content.decode("utf-8", "replace")
        self.assertIn('href="https://www.ielts.org"', body)

    def test_plain_name_has_no_link_when_url_blank(self):
        body = self.client.get("/uz/", follow=True).content.decode("utf-8", "replace")
        # "Pearson" is seeded with a blank website_url — must render as plain
        # text (a <span>), not wrapped in a link.
        self.assertIn("<span>Pearson</span>", body)

    def test_section_hidden_when_no_partners(self):
        Partner.objects.all().delete()
        body = self.client.get("/uz/", follow=True).content.decode("utf-8", "replace")
        self.assertNotIn("marquee-track", body)

{% if partners %}
<div class="bg-alt border-y bd py-5">

    <div class="marquee">

        {% for p in partners %}{% if p.website_url %}<a href="{{ p.website_url }}" target="_blank" rel="noopener" class="hover:text-brand-blue-600 transition">{{ p.name }}</a>{% else %}<span>{{ p.name }}</span>{% endif %}{% endfor %}
        {% for p in partners %}{% if p.website_url %}<a href="{{ p.website_url }}" target="_blank" rel="noopener" class="hover:text-brand-blue-600 transition">{{ p.name }}</a>{% else %}<span>{{ p.name }}</span>{% endif %}{% endfor %}
      </div>
    </div>
  </div>
</div>
{% endif %}
```

Note: the partner list is deliberately looped twice in the same track — the CSS animation (`assets/css/source.css`, `.marquee-track { animation: scrollx 26s linear infinite; }` / `@keyframes scrollx { to { transform: translateX(-50%); } }`) scrolls the track left by exactly half its width to loop seamlessly; that only looks seamless if the second half is an exact duplicate of the first.
